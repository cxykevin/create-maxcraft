# Create: MaxCraft

给《机械动力》加一点“大一号”的东西：**大包裹、大合成网格、大合成器阵列**。

《机械动力》原本把很多东西卡死在“九”上 —— 一个包裹最多九组、一块仪表最多 3×3 的合成配方。这个模组把这些限制放开：包裹想装多少装多少，合成网格想多大就多大，机器也会把一整批原料按正确的形状铺进大阵列里。

适用于 **Minecraft 1.21.1 + NeoForge**，需要 **机械动力（Create）6.0.10** 或更高版本。
安装 *机械动力：赛博护目镜（Create: Cyber Goggles）* 体验更好，但不是必须的。

## 新增物品

| 物品 | 怎么获得 |
| --- | --- |
| **大型包裹构件** | 序列组装：坚固板 → 用精密构件部署 → 冲压 |
| **大型打包机** | 工作台：打包机 + 大型包裹构件；或手持构件右键一台打包机直接升级 |
| **大型理包机** | 工作台：理包机 + 大型包裹构件；或手持构件右键一台理包机直接升级 |
| **扩展仓储发报机** | 工作台：仓储发报机 + 大型包裹构件；或手持构件右键一台仓储发报机直接升级 |
| **扩展工厂仪表** | 工作台：工厂仪表 + 大型包裹构件 |

大型打包机和大型理包机可以在工作台上互相转换（就像《机械动力》里打包机和理包机本身那样），不需要额外材料。
原地升级会保留机器里的一切：物流网络、设置、夹着的包裹、写的地址都不会丢。

## 大型打包机与大型理包机

* **大型打包机**一次能装 27 组（可在配置里调），装出来的还是一个普通包裹，只是很大 —— 蛙港、邮筒、拆包机、理包机都照常处理。
* **大型理包机**会把**整个订单**合并成**一个**包裹，并且**等到货物全部到齐**才合并。红石请求这类没有订单信息的包裹，仍然按原来的方式合并。
* **包裹不会凭空少东西。** 无论包裹多大，拆包、掉落、锯开、合并都会把内容完整传递下去。
* 想装得更多，改服务端配置里的 `maxPackageStacks` 即可（见文末）。

## 扩展仓储发报机

和普通仓储发报机一样，但它允许的**物品种类从 9 种提升到 27 种**。订单栏仍然只有九格宽，多出来的种类会显示成 `[+N]`，点物品栏里的物品仍然可以调整它们的数量（这是《机械动力》本来的做法）。

## 扩展工厂仪表

它不是新方块，而是**带着合成网格尺寸的工厂仪表**。

* **每个面板各管各的。** 一块仪表上最多四个面板，等于四台机器共用一块方块：每格自己记自己的网格尺寸，升级一格不会影响另外三格。
* **怎么升级。** 手持**大型包裹构件**右键某个面板；或者用**扩展工厂仪表**物品去加面板。**已经有面板的格子会直接拒绝**：不改尺寸、也不消耗手上的东西。
* **物品可以堆叠。** 扩展工厂仪表物品只记录一个网格尺寸，所以同尺寸的都是同一种物品、能堆在一起。尺寸具体落到哪一格，是你**用它的那一刻**决定的。
* **掉落物是光板。** 用镐子挖掉、或用扳手拆下面板，掉出来的是一个**没有绑定网络的**扩展仪表 —— 和刚从工作台拿到的仪表一样，要先拿它右键**仓储发报机**绑定网络，才能放下去。
* **世界里的样子。** 使用大网格的面板会显示成**黄铜色**，普通面板保持原样，一眼就能分辨。
* **面板界面。** 打开合成模式后，面板显示的是**材料列表**（超过九个用下方的 ‹ › 按钮翻页），把鼠标停在上面会弹出**这个配方本来的形状**预览。普通仪表的面板界面完全没变。

## 用大配方合成

1. 把面板的网格尺寸调大（用大型包裹构件右键，或用扩展仪表放下来）。
2. 在面板里设好产物，把配方需要的原料接到面板上，并**打开“使用动力合成”**（面板左侧那个 3×3 图标的按钮），然后关闭面板保存。
3. 面板会把订单交给物流网络，打包机打包、投递，大阵列就会按配方摆好并开始合成。

几点说明：

* 比网格小的配方（比如 3×3 放到 5×5 上）会摆在网格的**左上角**，其余留空，机器收到的仍然是完整尺寸的图案。
* 图案的行列是**按阵列本身的行宽**铺的，所以 10×10 的配方放进 12×12 的阵列就是一个正方的 10×10，不会错位。
* 一个包裹里装了“好几批原料”时，多余的原料会**平均铺到需要它的那些格子**上，而不是全塞进第一台合成器。

## 配置

服务端配置 `maxcraft-server.toml`（单人游戏在存档目录的 `serverconfig/` 下，服务器在 `config/` 下）：

```toml
# 单个包裹最多能装多少组。大型打包机一次装这么多组，理包机合并出来的包裹也最多这么大。
# 默认 64，范围 1 ~ 4096。
maxPackageStacks = 64
```
